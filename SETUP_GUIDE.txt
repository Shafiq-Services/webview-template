================================================================================
  QUICK START (3 STEPS)
================================================================================

STEP 1: Basic App Configuration
--------------------------------
File: lib/config/app_config.dart

Change these values:
  - appName: Your app name
  - mainUrl: Your website URL
  - oneSignalAppId: Your OneSignal ID (for push notifications)
  - Colors: Your brand colors
  
  - Install rename tool:
    flutter pub global activate rename

  - Change bundle ID:
    rename setBundleId --targets ios,android --value "com.company.appname"

  - Change app name:
    rename setAppName --targets ios,android --value "MyApp"

  - Change app icon:
    Edit: icons_launcher.yaml
    Run: dart run icons_launcher:create


STEP 2: Payment Configuration (OPTIONAL - skip if no payments)
--------------------------------
File: lib/config/payment_config.dart

Change these values:
  - revenueCatApiKey: iOS and Android keys from RevenueCat
  - base44Url: Your backend URL
  - base44ApiKey: Your backend API key

This file is ONLY for API keys. Nothing else needed!


STEP 3: WebView Configuration (OPTIONAL - skip if no customization)
--------------------------------
File: lib/config/webview_config.dart

Two types of configuration:

A) Subscription Buttons (if using payments)
   - Add button XPath and RevenueCat product ID
   - Get XPath: Chrome DevTools → Right-click element → Copy XPath

B) Hide Elements (if hiding parts of website)
   - Add element XPath to hide list
   - Get XPath: Same as above



================================================================================
  PROJECT STRUCTURE
================================================================================

lib/
├── config/                      ← ALL CONFIGURATION HERE
│   ├── app_config.dart          (Basic: name, URL, colors)
│   ├── payment_config.dart      (Payments: API keys only)
│   └── webview_config.dart      (WebView: buttons, hiding)

================================================================================
  PAYMENTS: HOW IT WORKS
================================================================================

Flow:
  User clicks button in webview
    ↓
  App intercepts click (via XPath)
    ↓
  Opens RevenueCat payment sheet
    ↓
  After successful purchase, syncs to Base44 backend
    ↓
  Webview automatically shows new subscription status

Key Points:
  - All payment logic is handled automatically
  - No need to write payment code
  - Just configure button XPaths and product IDs
  - Backend sync is automatic (if enabled)
