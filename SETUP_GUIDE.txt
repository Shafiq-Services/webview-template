WebView Template — Quick setup
================================

1) Configuration (only these three files under lib/config/)
   - app_config.dart     — App name, URLs, colors, OneSignal app ID, deliveryMilestone, deep links (customScheme, deepLinkDomains), optional shareRecipeApiUrl (M4+).
   - payment_config.dart — RevenueCat keys (iOS/Android), product IDs, entitlement id, optional Base44 sync URL/key.
   - webview_config.dart — Subscription button XPaths → product IDs, hide elements.

2) Initialization
   - main.dart calls await AppInitializer.initialize() (WebView debug, DeepLinkService, NotificationService when milestone >= 2).

3) Deep links
   - Match AndroidManifest intent-filters and iOS CFBundleURLTypes / associated domains to app_config customScheme and deepLinkDomains.

4) Milestones
   - See .cursor/rules/milestones.mdc — set deliveryMilestone to the scope you are shipping.

5) Rename package / app name (when forking)
   - flutter pub run change_app_package_name:main com.yourcompany.app
   - flutter pub run rename setAppName --targets ios,android --value "Your App"

6) Build
   - See BUILD_SETUP.md and build_releases.sh

Architecture principles are in .cursor/rules/project-rules.mdc.
